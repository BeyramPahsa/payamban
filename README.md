# پیام‌بان

اپ اندروید برای مرتب کردن پیامک‌های گوشی:

- **گفتگوها** — پیام مخاطبین، پیام‌های شخصی، بانکی و کد تأیید دست‌نخورده می‌مانند.
- **تبلیغات** — پیامک‌های تبلیغاتی شناسایی و جدا می‌شوند؛ **هیچ‌چیز بدون تأیید شما حذف نمی‌شود**.
- **کد تخفیف** — کدها از داخل متن پیامک بیرون کشیده و در تبی جدا نگه داشته می‌شوند، حتی بعد از حذف خود پیام.
- **بلاک** — فرستندهٔ تبلیغاتی که بلاک شود، پیام بعدی‌اش اصلاً روی گوشی ذخیره نمی‌شود.

همهٔ تحلیل روی خود گوشی انجام می‌شود. اپ به اینترنت وصل نمی‌شود و هیچ پیامکی جایی فرستاده نمی‌شود.

## چطور تشخیص می‌دهد؟

بر پایهٔ قواعد پیامک فارسی، نه حدس تصادفی:

| نشانه | اثر |
|---|---|
| عبارت «لغو ۱۱» و مانند آن (امضای قانونی تبلیغات در ایران) | ۶۰+ امتیاز |
| ارسال از سرشمارهٔ انبوه به‌جای شمارهٔ موبایل | ۱۲+ |
| واژگان تبلیغاتی (تخفیف، جشنواره، وام، ثبت‌نام...) | تا ۴۰+ |
| وجود لینک | ۱۲+ |
| شمارهٔ موبایل شخصی | ۳۵− |
| واژگان مهم (مصاحبه، قرارداد، مرسوله، دادگاه...) | ۳۰− |

مخاطبین، کد تأیید و پیام‌های تراکنش بانکی پیش از امتیازدهی کنار گذاشته می‌شوند و هرگز تبلیغاتی شمرده نمی‌شوند.
حساسیت در تنظیمات قابل تغییر است.

## ساخت فایل نصبی

نیازی به نصب هیچ ابزاری روی کامپیوتر نیست. با هر `push` روی شاخهٔ `main`،
GitHub Actions به‌صورت خودکار فایل `payamban.apk` را می‌سازد و در بخش
**Releases** همان مخزن قرار می‌دهد.

دستی هم می‌شود اجرا کرد: تب **Actions** ← *ساخت فایل نصبی اپ* ← **Run workflow**.

## اجازه‌های لازم

| اجازه | چرا |
|---|---|
| خواندن و دریافت پیامک | تحلیل و دسته‌بندی |
| ارسال پیامک | پاسخ دادن داخل اپ |
| مخاطبین | تشخیص اینکه فرستنده را می‌شناسید |
| اپ پیش‌فرض پیامک | اندروید فقط به اپ پیش‌فرض اجازهٔ **حذف** پیامک و جلوگیری از پیام بلاک‌شده را می‌دهد |
